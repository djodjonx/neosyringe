# Alternatives

A comparison based on what each project's own documentation says, read on **2026-11-06**. Nothing here comes from memory or from a benchmark.

## How to read this page

- A cell says what the cited page states. "Not stated on the page read" means only that the page did not say it. It does not mean the library lacks the feature.
- Typing, performance and bundle size of other libraries are **not compared**. They were not evaluated. A fair size or speed comparison needs the same features on both sides, a method and a dispersion. The only NeoSyringe numbers published are in the [profiles guide](./profiles.md).
- The NeoSyringe column cites this repository.

## Capabilities documented

| Capability | NeoSyringe | tsyringe | Awilix | InversifyJS |
|------------|------------|----------|--------|-------------|
| Classes need decorators | No. Plain classes (`README.md`) | Yes. The README asks for `experimentalDecorators` and `emitDecoratorMetadata` [1] | Not stated on the page read [2] | The page uses `@injectable` and `@inject` and asks to enable decorator options [3] |
| `reflect-metadata` or a `Reflect` polyfill | Not used | The README asks for a polyfill, and uses `reflect-metadata` in its examples [1] | Not stated on the page read [2] | `reflect-metadata` is in the install step [3] |
| Child containers | `useContainer` parent, and `createScope()` (`packages/neosyringe/src/types.ts:46`) | `createChildContainer()`: absent registrations resolve from the parent [1] | `createScope()` [2] | Not stated on the page read [3] |
| Lifetimes | `singleton` (default), `transient` (`packages/neosyringe/src/types.ts:12`) | Transient (default), Singleton, ResolutionScoped, ContainerScoped [1] | `TRANSIENT` (default), `SCOPED`, `SINGLETON` [2] | Not stated on the page read [3] |
| Disposal | `destroy()` closes owned instances with a `dispose` function (see [states and ownership](./states-and-ownership.md)) | Disposable instances are disposed with `container.dispose()`; async disposal can be awaited [1] | `container.dispose()` and `.disposer()` [2] | Not stated on the page read [3] |
| Async resolution | `resolve()` stays synchronous. Async factories are awaited once in `initialize()` (see [async factories](./async-factories.md)) | Not documented in the README read: resolve examples are synchronous [1] | Not stated on the page read [2] | Not stated on the page read [3] |
| Dependency graph checked at build time | Yes, by the build plugin, the CLI and the IDE plugin (see [CLI](./cli.md)) | Not evaluated | Not evaluated | Not evaluated |

## What NeoSyringe asks in return

- A build step. The container is generated by a plugin, so `defineBuilderConfig(...)` throws if it runs without the plugin (`packages/neosyringe/src/types.ts:352`).
- Strict contracts: factories declare their `dependencies`, and `destroy()` is final. See [states and ownership](./states-and-ownership.md).
- Tokens are checked inside one TypeScript program. Crossing a compiled package boundary needs the explicit token manifest protocol, and an undeclared boundary is reported (`NEO_TOKEN_BOUNDARY_UNSUPPORTED`, `packages/core/src/analyzer/shared/tokensManifest.ts:66` and `packages/core/src/analyzer/collectors/ConfigCollector.ts:433`).
